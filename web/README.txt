双击启动网页.command（Mac）或启动网页.bat（Windows，需 Python 3）。
手动启动：python3 website-source/c09-viewer/serve.py --port 8809 --open
地址：http://127.0.0.1:8809/
拖动旋转，滚轮靠近，右键/双指平移；菜单切换全景、远眺、庭院、细部、漫游及原图。
画质可切换标准/精细/流畅。S 显示统计。Esc 中断漫游。
画面静止或查看原图时暂停重复绘制，交互时恢复。
不需要 VMware、Node 或联网 CDN。不要直接双击 index.html。
本机地址不等于公开参赛链接；可直接上传同目录的 4K/60fps MP4。
